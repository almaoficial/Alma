# Detalle de uso — hola-mundo

Este archivo existe para demostrar **progressive disclosure**: no se
carga en el índice; el agente lo abre solo cuando decide usar la skill.

## Procedimiento

1. Leer el cuerpo de `SKILL.md`.
2. Responder con un saludo breve en español (ej: «¡Hola! ¿En qué te ayudo?»).
3. No agregar explicaciones salvo que el usuario las pida.

## Cuándo NO usarla

Si el usuario ya saludó en este turno, no volver a saludar.
